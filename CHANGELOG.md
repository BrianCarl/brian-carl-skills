# Changelog

Notable changes to the published skills and installation guidance are recorded here. Skills CLI users receive changes when they run an update command.

## 2026-10-07

### Added

- Hook Reviewer (`review-hooks`): a relevance-first review checklist, emotional language and formula banks, three distinct alternatives, and a supported recommendation.
- README commands for installing both skills or individual skills, selecting an agent, and updating global or project installations.
- This changelog for tracking published changes.

### Clarified

- Hook relevance comes first; specificity and emotion make the audience's reason to care recognizable.
- Credibility checks should match the claim and can rely on context, examples, demonstrations, or reasoning.
- Personal preferences should be supplied separately from installed skill files to avoid losing local edits during updates.
